# PRD: ShopMate

## 목표
여러 판매자가 각자 상품을 올리고, 손님이 한 번에 담아 결제(모의)까지 끝낼 수 있는 최소 마켓플레이스를 만든다.

**완료 기준**: 비로그인 방문자가 첫 화면에서 주문 완료까지, 로그인 1회 외에 막히는 지점 없이 도달한다.

## 사용자
- **구매자** — 로그인 없이 상품을 둘러보고 장바구니에 담는다. 주문할 때만 로그인한다.
- **판매자** — 자기 상품을 등록·수정·삭제하고, 자기에게 들어온 주문을 발송 처리한다. **다른 판매자의 상품과 주문은 볼 수 없다.**
- **운영자(admin)** — 전체를 조회할 수 있고 판매자 권한을 부여한다. 전용 화면은 MVP에서 만들지 않는다.

## 핵심 기능
1. **상품 카탈로그** — 목록(카테고리 필터·이름 검색), 상세 페이지. 상세에 판매자(스토어)명을 표시한다.
2. **장바구니** — 담기/수량 변경/삭제. 비로그인은 브라우저에 저장, 로그인하면 서버 장바구니로 병합. **판매자별로 묶어서 보여준다.**
3. **인증** — 이메일+비밀번호 회원가입·로그인·로그아웃. 가입 시 "판매자로 가입"을 선택할 수 있다.
4. **주문** — 체크아웃에서 배송지 입력 → 주문 생성(결제는 모의 승인) → 재고 차감 → 주문 내역 조회.
   한 번의 결제 안에서 **판매자별로 주문 그룹이 나뉜다.** A 판매자는 오늘, B 판매자는 모레 보낼 수 있기 때문이다.
5. **주문 취소** — 아직 발송되지 않은(`paid`) 그룹을 구매자 또는 해당 판매자가 취소할 수 있다. **취소하면 재고가 복구된다.**
6. **판매자 콘솔** — 내 상품 CRUD, 내 주문 그룹 목록과 발송 처리.

## MVP 제외 사항
- 실제 결제 PG 연동 (토스페이먼츠·아임포트 등). 결제는 항상 성공하는 모의 처리.
- **운영자 전용 화면.** `admin` 역할은 RLS에서 전체 조회 권한만 갖고, 화면은 판매자 콘솔을 재사용한다. 판매자 권한 부여는 SQL로 한다.
- **정산·수수료·판매자 심사.** 판매자는 가입 즉시 상품을 올릴 수 있다.
- 배송 추적, 반품/환불 플로우. 부분 취소(그룹 안의 일부 상품만 취소).
- 리뷰·평점, 위시리스트, 쿠폰·프로모션.
- 이미지 직접 업로드. 상품 이미지는 외부 URL 문자열로만 받는다.
- 소셜 로그인, 이메일 인증 메일, 비밀번호 재설정.
- 다국어, 다크모드.

## 화면
| 경로 | 설명 |
|------|------|
| `/` | 상품 목록 + 카테고리 필터 + 검색 |
| `/products/[id]` | 상품 상세 + 판매자명 + 장바구니 담기 |
| `/cart` | 장바구니 (판매자별 그룹 + 그룹별 배송비) |
| `/checkout` | 배송지 입력 + 주문 확정 |
| `/orders` | 내 주문 내역 |
| `/orders/[id]` | 주문 상세 — 판매자 그룹별 상태, 취소 |
| `/login`, `/signup` | 인증 (가입 시 판매자 선택) |
| `/seller/products` | 판매자 — 내 상품 CRUD |
| `/seller/orders` | 판매자 — 내 주문 그룹, 발송 처리 |

## 규칙 (제품 레벨)

### 가격·배송비
- **배송비는 판매자별로 계산한다.** 한 판매자에게서 산 금액의 소계가 **50,000원 이상이면 0원, 미만이면 3,000원**.
  주문 전체 기준으로 하면 A에서 3만원, B에서 3만원 산 손님이 무료배송을 받게 되어 판매자마다 배송 원가가 어긋난다.
- 장바구니와 체크아웃에서 **소계 / 배송비 / 합계를 각각 따로 보여준다.** 무료배송까지 남은 금액도 판매자별로 안내한다.
- 주문에는 **주문 당시의 가격을 스냅샷으로 저장한다.** 이후 상품 가격이 바뀌어도 과거 주문 금액은 변하지 않는다.

### 재고
- 재고가 0인 상품은 **목록에 그대로 노출하되 "품절"로 표시**하고 장바구니에 담을 수 없다. 목록 순서는 등록순이며 품절이라고 뒤로 밀지 않는다.
- 주문 확정 시점에 재고가 부족하면 **주문 전체를 실패시키고** 어떤 상품이 몇 개 부족한지 알려준다. 부분 주문을 만들지 않는다.

### 로그인 전환
- 로그인이 필요한 지점(체크아웃)에서 튕겨 나갔다면, 로그인 후 **원래 가려던 화면으로 돌아온다.** 홈으로 보내지 않는다.
- 로그인하면 브라우저에 있던 장바구니가 서버 장바구니와 합쳐진다. 같은 상품은 수량을 더하고, 재고를 넘으면 재고만큼으로 줄인다.

### 주문 취소
- 취소 단위는 **판매자 그룹**이다. 주문 전체가 아니라 "A 판매자 건"을 취소한다.
- 아직 `paid` 상태인 그룹만 취소할 수 있다. 이미 발송(`shipped`)된 그룹은 취소 불가.
- 구매자 본인과 해당 판매자 모두 취소할 수 있다.
- **취소하면 그 그룹의 상품 재고가 복구된다.** 여러 번 눌러도 한 번만 복구되어야 한다.

### 권한
- 판매자는 자기 상품과 자기 주문 그룹만 다룰 수 있다. 이 격리는 화면이 아니라 데이터베이스 정책(RLS)이 보장한다.
- 판매자는 발송을 위해 자기 그룹이 속한 주문의 **배송지를 볼 수 있다.** 그 손님이 다른 판매자에게서 무엇을 얼마에 샀는지는 볼 수 없다.
- 사용자가 스스로 `admin`이 되는 경로는 존재하지 않는다.

## 디자인
- 라이트 모드 고정. 상품 사진이 주인공이므로 UI는 물러선다.
- 무채색(흰 배경 + 회색 계열) + 포인트 색 1가지.
- 커머스지만 "세일 배너로 도배된 쇼핑몰"이 아니라 정돈된 카탈로그처럼 보여야 한다.
- 자세한 색상·컴포넌트 규칙은 `docs/UI_GUIDE.md`.
