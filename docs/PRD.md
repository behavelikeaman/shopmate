# PRD: ShopMate

## 목표
소규모 판매자가 상품을 등록하고, 방문자가 담고 결제(모의)까지 끝낼 수 있는 최소 온라인 쇼핑몰을 만든다.

## 사용자
- **구매자** — 로그인 없이 상품을 둘러보고 장바구니에 담는다. 주문할 때만 로그인한다.
- **판매자(관리자)** — 상품을 등록·수정·삭제하고, 들어온 주문을 확인한다.

## 핵심 기능
1. **상품 카탈로그** — 목록(카테고리 필터·이름 검색), 상세 페이지.
2. **장바구니** — 담기/수량 변경/삭제. 비로그인은 localStorage, 로그인하면 서버 장바구니로 병합.
3. **인증** — Supabase Auth 이메일+비밀번호 회원가입·로그인·로그아웃.
4. **주문** — 체크아웃에서 배송지 입력 → 주문 생성(결제는 모의 승인) → 재고 차감 → 주문 내역 조회.
5. **관리자** — 상품 CRUD, 주문 목록 조회 및 상태 변경.

## MVP 제외 사항
- 실제 결제 PG 연동 (토스페이먼츠·아임포트 등). 결제는 항상 성공하는 모의 처리.
- 배송 추적, 반품/환불 플로우.
- 리뷰·평점, 위시리스트, 쿠폰·프로모션.
- 이미지 직접 업로드 (Supabase Storage). 상품 이미지는 외부 URL 문자열로만 받는다.
- 소셜 로그인, 이메일 인증 메일, 비밀번호 재설정.
- 다국어, 다크모드.

## 화면
| 경로 | 설명 |
|------|------|
| `/` | 상품 목록 + 카테고리 필터 + 검색 |
| `/products/[id]` | 상품 상세 + 장바구니 담기 |
| `/cart` | 장바구니 |
| `/checkout` | 배송지 입력 + 주문 확정 |
| `/orders` | 내 주문 내역 |
| `/login`, `/signup` | 인증 |
| `/admin/products` | 관리자 상품 CRUD |
| `/admin/orders` | 관리자 주문 목록 |

## 규칙 (제품 레벨)
- 재고가 0인 상품은 목록에 "품절"로 표시하고 장바구니에 담을 수 없다.
- 주문 확정 시점에 재고가 부족하면 주문을 실패시키고 이유를 보여준다.
- 주문에는 **주문 당시의 가격을 스냅샷으로 저장**한다. 이후 상품 가격이 바뀌어도 과거 주문 금액은 변하지 않는다.

## 디자인
- 라이트 모드 고정. 상품 사진이 주인공이므로 UI는 물러선다.
- 무채색(흰 배경 + 회색 계열) + 포인트 색 1가지.
- 커머스지만 "세일 배너로 도배된 쇼핑몰"이 아니라 정돈된 카탈로그처럼 보여야 한다.
